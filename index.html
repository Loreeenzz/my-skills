How the Skills Vault Works

        

        
      


      

        
All skills live in a single Git-backed repository (my-skills/skills/*) and are symlinked into your global or project-level AI agent directories:


        

          
my-skills/skills/ (Single Source of Truth)

          
  ├── git-commit-message/SKILL.md

          
  ├── session-handoff/SKILL.md

          
  ├── prospect-standards-implement/SKILL.md

          
  ├── prospect-standards-migrate/SKILL.md (+ references/coverage.md)

          
  └── prospect-standards-review/SKILL.md

          
      │

          
      ├──► ~/.gemini/config/skills/*          (Global Antigravity / Gemini)

          
      ├──► ~/.config/opencode/skills/*       (Global OpenCode CLI)

          
      ├──► ~/.claude/skills/*                (Global Claude Code)

          
      └──► <workspace>/.agents/skills/*      (Project-specific workspace)

        


        

          

            1. Instant Live Sync
            
Because skills are linked via symlinks, editing any file inside my-skills/skills/ updates all connected agents immediately.

          

          

            2. Progressive Disclosure
            
Agents only read the 2-line YAML frontmatter at startup (~50 tokens), loading the full runbook and reference docs only when invoked.
